# Thiranex Task 3 — JavaScript Logic & State Management

Interactive client-side To-Do List built with HTML5, CSS3 and Vanilla JavaScript.

## Requirements covered
- Full CRUD: create, read, update, delete
- `window.localStorage` persistence across reloads
- All / Active / Completed filtering
- Dynamic DOM elements and event handling
- Responsive UI
- Accessible labels and live task count

## Run
Open `index.html` in a browser or use VS Code Live Server.

## GitHub Pages
Deploy from `main` branch and `/ (root)`.
